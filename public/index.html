Risk scanning

Ethereum tokens are checked by default with GoPlus Security (free, no key needed). For an extra layer, honeypot.is adds buy/sell simulation — it needs its own free API key. Add HONEYPOT_API_KEY in your Netlify environment variables to enable it; without it, GoPlus alone still covers honeypot detection.
